# Work anxiety pattern

Public-safe working model. Not a diagnosis.

## Pattern

Yuriy currently has two independent work tracks. Both can contain routine-heavy open loops. When those loops remain only in memory, they can continue running at night and contribute to early waking or fragmented sleep.

## Evening task dump protocol

Use this as a practical lever, especially when work stress is active.

For each work track, write no more than three open items:

```text
Work 1
1. Open item:
   First physical action tomorrow:
2. Open item:
   First physical action tomorrow:
3. Open item:
   First physical action tomorrow:

Work 2
1. Open item:
   First physical action tomorrow:
2. Open item:
   First physical action tomorrow:
3. Open item:
   First physical action tomorrow:

Not under my control tonight:
-
```

## Messaging rule

Do not tell Yuriy to "calm down". The useful action is externalization: turn open loops into written queues with first actions.

Good message:

"Tonight's useful move is not to solve both jobs. It is to move both queues out of your head: three items per work track, first action for tomorrow, and one line for what is not controllable tonight."
